일반판매 고객 867 / 장소 7110 · 로켓그로스 고객 8378700664 / 장소 7120. 일반판매는 조회한 주문 중 구매확정 건만 출력합니다. API 주문 검색일과 구매확정일은 다르므로 필요한 과거 주문도 충분히 조회해야 합니다. 엑셀 방식도 일반판매는 API 데이터를 사용합니다.
