쿠팡 API 연결

판매자 ID와 Access Key, Secret Key를 입력하세요. 두 채널에 같은 판매자 인증을 사용합니다.

저장한 키는 이 브라우저의 localStorage에 보관됩니다. 공유 PC에서는 저장하지 마세요. Secret Key는 서버로 전송하지 않으며 서명은 브라우저에서 생성합니다.
